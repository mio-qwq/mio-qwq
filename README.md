## Projects

### [SandCore](https://github.com/mio-qwq/SandCore)
An experimental 32-bit x86 operating system featuring paging, preemptive scheduling, the SandFS filesystem, a multi-user graphical desktop, and in-system C development tools, including a compiler, assembler, and debugger.

### [MioRV](https://github.com/mio-qwq/miorv)
A RISC-V RV32IMAC processor built from scratch, supporting M/S/U privilege levels, Sv32 virtual memory, exceptions, and interrupts. It has successfully booted Linux in RTL simulation.

### [MioLinux](https://github.com/mio-qwq/mio-linux)
A lightweight RV32 Linux system for MioRV, built with Linux, musl, and BusyBox, with a development environment including GCC, Binutils, and Make.

### [Stardust-Core](https://github.com/mio-qwq/Stardust-Core)
An experimental RISC-V processor project featuring a single-cycle RV32I core built from scratch.

### Asterion
An experimental custom dataflow processor exploring wide-issue execution, speculative execution, branch prediction, state forwarding, and a custom ISA.

### [Mathematical Research](https://github.com/mio-qwq/math)
Research in graph theory, combinatorics, and related areas, with proofs, counterexamples, reproducible computations, and Lean formalizations. A [public preprint](https://doi.org/10.5281/zenodo.23293088) is available on Zenodo; it has **not yet been peer reviewed**.

### [MioCrypt](https://github.com/mio-qwq/MioCrypt)
A PKWCTF 2026 Windows x64 reverse engineering challenge involving Win32 programming, RSA-OAEP key encapsulation, and cyclic XOR-based file encryption.

### [Empty City (空城计)](https://github.com/mio-qwq/empty-city-ctf)
A PKWCTF 2026 Windows x86 reverse engineering challenge combining PE TLS callbacks, vectored exception handling (VEH), and XTEA to conceal execution logic and input validation.
