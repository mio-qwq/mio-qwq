## Projects

### [MioRV](https://github.com/mio-qwq/miorv)
从零实现的 RV32IMAC RISC-V 处理器，支持 M/S/U 特权级、Sv32、异常与中断，并已通过 RTL 仿真启动 Linux。

### [MioLinux](https://github.com/mio-qwq/mio-linux)
面向 MioRV 的轻量级 RV32 Linux 系统，基于 Linux、musl 与 BusyBox，并提供包含 GCC、Binutils 和 Make 的开发环境。

### [Stardust-Core](https://github.com/mio-qwq/Stardust-Core)
RISC-V 处理器实验项目，包含从零实现的单周期 RV32I 核心。

### Asterion
自定义数据流处理器实验项目，探索宽发射、推测执行、分支预测、状态转发与自定义 ISA。
